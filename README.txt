موقع MA للتسويق والإعلان — ملفات جاهزة للتعديل
================================================

محتويات المشروع
- index.html        هيكل الموقع والنصوص.
- css/style.css     الألوان والتنسيق والتصميم المتجاوب للموبايل والكمبيوتر.
- js/script.js      قائمة الموبايل، شريط الأعمال، وتحميل الإعدادات.
- site-config.txt   الملف الأساسي لتغيير روابط الموقع ومسارات الصور والبيانات.
-            الصور الافتراضية المستخدمة بالموقع.
- code_txt/         نسخ نصية من ملفات HTML وCSS وJavaScript عند الحاجة لفتحها كمستندات نصية.

تغيير اللوجو والصور والروابط
1. افتح site-config.txt ببرنامج Notepad أو أي محرر نصوص.
2. غيّر القيمة الموجودة بعد علامة = فقط، مع إبقاء اسم المفتاح كما هو.
3. ضع الصور الجديدة داخل مجلد assets ثم اكتب مسارها، مثال: my-logo.png
4. ضع الروابط الحقيقية مكان روابط التواصل الاجتماعي وروابط المشاريع الافتراضية.
5. احفظ الملف وأعد تحميل الموقع.

تشغيل الموقع على الكمبيوتر
- افتح مجلد المشروع في محرر مثل VS Code وشغّل إضافة Live Server، أو
- إذا كان Python مثبتًا، افتح Terminal داخل مجلد المشروع واكتب:
  python -m http.server 8000
  ثم افتح المتصفح على: http://localhost:8000

مهم: تحميل site-config.txt تلقائيًا يحتاج تشغيل الموقع عبر خادم محلي أو رفعه إلى استضافة؛ فتح index.html مباشرة قد يمنع المتصفح قراءة ملف الإعدادات بسبب قيود الأمان. في هذه الحالة يظل الموقع يعرض القيم الافتراضية المكتوبة داخله.

قبل النشر
- استبدل أرقام الهاتف والبريد والعنوان والروابط الوهمية ببياناتك الصحيحة.
- راجع صور معرض الأعمال لأنها صور تجريبية مأخوذة/مشتقة من المرجع وليست أعمالًا مستقلة جديدة.
- إذا غيّرت اسم ملف CSS أو JavaScript، حدّث مساره في index.html.
